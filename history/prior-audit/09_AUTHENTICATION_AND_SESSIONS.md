# Authentication,authorization and sessions

[Master index](00_MASTER_INDEX.md)

No logged-in browser/session/HAR/cookie export was available. Login/logout/registration/password-reset mechanisms and cookie/token values were not recovered as verified workflows. Generated route names and token-related schema fields are declarations only. Local entitlement patches cannot be reported as server account authorization changes. All secret-like literals and fixture handles in copied evidence were redacted; originals are unmodified.
