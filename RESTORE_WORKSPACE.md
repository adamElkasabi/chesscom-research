# Workspace restoration

[Master index](00_MASTER_INDEX.md)

To use the selective restore helper, copy tools/restore-workspace.py beside website-complete-forensic-audit.zip, then run python3 restore-workspace.py --list. The helper restores original engine paths only after checking hashes and available snapshot headroom. The source extension code and existing research/release archives remain in the workspace; the active engine is archived in this delivery and needs restoration before execution. Download and inspect the audit outside the capped workspace for full browsing.
